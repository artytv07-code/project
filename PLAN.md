## 2. Ключевые решения

### Стек

- React 19 + TypeScript + Vite.
- Framer Motion — переходы, текстовые reveal-анимации, варианты сцен.
- Lucide React — только минималистичные иконки (звук, назад, информация, сердце).
- `@fontsource` — локальные Cormorant Garamond и Manrope с кириллицей, без внешних CDN и без запросов к Google Fonts.
- Обычный структурированный CSS + CSS-переменные; без UI-китов и тяжёлых библиотек.
- Без backend, аналитики, cookies, localStorage, аккаунтов и сбора данных.

### Архитектура приложения

Одностраничное приложение с конечным автоматом сцен. URL не меняется; после перезагрузки история начинается с интро. Состояние — только в памяти.

```
App
├── SceneTransition (AnimatePresence, fade/blur/scale)
├── AmbientParticles (canvas, низкая плотность)
├── ProgressIndicator (тонкая линия + 5 точек)
├── AudioController (появляется после интро)
├── BackButton (на сценах 1–5, не на интро/финале)
└── scenes/
    ├── IntroScene
    ├── CityScene
    ├── DetailsScene
    ├── IntrigueScene
    ├── InvitationScene
    ├── DetailsPanel
    └── FinalScene
```

Дополнительно:

- `SceneBackground` — единый компонент фона: `picture`, `srcset`, AVIF/WebP, LQIP-заглушка, плавное проявление, градиентные скримы.
- `CreditsSheet` — минимальная панель с авторами и лицензиями фотографий (открывается из финала и панели подробностей).
- `PrimaryButton`, `SecondaryButton`, `IconButton` — единые состояния, 48+ px, press-scale, focus-ring.
- Хуки: `useAudio`, `useSceneNavigation`, `useReducedMotion` (или встроенный Framer Motion), `useAppHeight` для фолбэка iOS.

- Вперёд — только осознанным действием пользователя (кнопки), кроме внутренней последовательности текста/кадров в сценах 1–2.

- Повторные нажатия во время перехода игнорируются (защита от двойного клика).

## 4. Визуальная система

### Композиция

- Полноэкранные фотографии с многослойными градиентами: глубокий синий сверху/снизу, тёплое золотое свечение в области фонарей.
- Виньетка, очень мелкое зерно (отдельная тайловая текстура), мягкая дымка.
- Стекло/полупрозрачность — только на маленьких контролах и панели подробностей; не превращать весь сайт в glassmorphism.
- Тонкие золотые линии, маленькие uppercase-подписи с увеличенным letter-spacing, крупные антиквенные заголовки.
- На десктопе — больше воздуха и деликатный pointer-параллакс; на тач-устройствах — slow zoom и без гироскопа.

### Анимации

- Fade in/out, crossfade, slow zoom, мягкий blur-переход, text reveal (opacity + y + blur), soft glow.
- Длительности 0.8–1.6 с, easing `cubic-bezier(0.22, 1, 0.36, 1)`.
- Не более 1–2 активных тяжёлых эффектов одновременно.
- `prefers-reduced-motion`: отключаются параллакс, бесконечный zoom и сложные blur-переходы; остаются короткие opacity-переходы. История полностью проходима.
- Частицы: canvas, 24–36 на мобильном, до 60 на десктопе; DPR не выше 1.5; пауза при скрытой вкладке; при reduced motion — статичные или 6–8 частиц.
- Свет: мягкие радиальные градиенты, мерцание дальних огней, блики; без искажения архитектуры.

### Кнопки

- Минимальная высота 48–52 px, на мобильном — удобная ширина, часто full-width до 360 px.
- Основная: тёплое золото/светлая поверхность с тёмным текстом, лёгкое свечение.
- Вторичная: прозрачная, золотая hairline-рамка, светлый текст.
- Press: scale 0.97 + brightness; focus-visible: золотое кольцо; hover только на fine pointer.
- `touch-action: manipulation`, `-webkit-tap-highlight-color: transparent`.

## 6. iPhone Safari, производительность, доступность

### iPhone

- `viewport-fit=cover`, `100dvh` с фолбэком, `env(safe-area-inset-top/bottom)`.
- `useAppHeight` — страховка для старых iOS при изменении адресной строки.
- Нет горизонтальной прокрутки; контент при переполнении скроллится вертикально, кнопки не перекрываются текстом (sticky-блок действий с градиентным скримом там, где нужно).
- Кнопки 48+ px, отступы от системных краёв, `touch-action: manipulation`.
- `-webkit-text-size-adjust: 100%`, отключение случайного выделения декоративных элементов, корректная смена ориентации.
- Проверка ширин: 320, 360, 375, 390, 393, 402, 430 px + ландшафт.

### Производительность

- Первый экран: hero preload + eager; остальные изображения — lazy/prefetch при входе в сцену.
- AVIF/WebP + JPEG fallback, `srcset`/`sizes`, художественные кропы под мобильный и десктоп.
- Бюджет: hero ≤ 300 КБ, шрифты ≤ 120 КБ, JS ≤ 200 КБ gzip, полная загрузка всех сцен ≤ 3 МБ.
- Без видео, 3D, GSAP, Lottie и тяжёлых UI-библиотек.
- Частицы с лимитом DPR и паузой в неактивной вкладке; CSS-анимации через transform/opacity.
- При медленной сети сразу виден фон/текст первой сцены, изображение проявляется после загрузки; при ошибке изображения — градиентная заглушка.

### Доступность

- `prefers-reduced-motion` — упрощённые переходы, без параллакса и бесконечного zoom.
- Контраст текста, читаемость на солнце/в темноте, `aria-label` у иконок, `aria-pressed` у звука.
- Клавиатурная навигация, видимый focus-ring, Escape закрывает кредиты.
- Смысловые заголовки, `aria-live` для смены сцены (аккуратно, без спама).

## 8. Тестирование

### Функциональное

- Все 7 экранов и обе ветки.
- Все переходы вперёд/назад, защита от двойных нажатий.
- Музыка: старт по жесту, пауза/продолжение, плавная громкость, скрытие при ошибке файла.
- «Посмотреть ещё раз»: сброс сцены, скролла, музыки.
- «Написать мне»: скрыта при пустой ссылке; при заданной — открывает мессенджер с предзаполненным текстом, не отправляет автоматически.
- Ошибки изображений/шрифтов/аудио не ломают историю.

### Визуальное

- 320, 360, 375, 390, 393, 402, 430 px, ландшафт, десктоп.
- Нет обрезанных заголовков, наложений текста на кнопки, горизонтальной прокрутки, скачков.
- Единая палитра и цветокоррекция всех сцен.
- Кириллица Cormorant/Manrope без подмены и «квадратиков».

### Техническое

- `npm run build`, `npm run typecheck`, `npm run preview`.
- Встроенный браузер: консоль, сеть, Lighthouse (accessibility/SEO/best practices), CPU-профиль, скриншоты.
- Playwright WebKit/Chromium на iPhone-размерах, если установка пройдёт; иначе — Chromium + iframe-стенд с фиксированными ширинами.
- Симуляция отсутствующих ассетов (временно переименовать файл, проверить fallback, вернуть).
- **Честно:** реальный iPhone Safari и реальный медленный мобильный интернет в этой среде недоступны; это остаётся на финальную проверку вам.

## 10. Риски и как их снимаю

| Риск | Решение |
|---|---|
| CC BY-SA требует атрибуции | Видимые кредиты + `CREDITS.md` + метаданные; или ваши личные фото |
| Дворец снят днём | Реальная фотография с сумеречной тонировкой, без ложной атрибуции; не выдаётся за ночной кадр |
| Нет реального iPhone | WebKit/Chromium-эмуляция + честный отчёт; финальная проверка на устройстве за вами |
| Нет ffmpeg/ImageMagick | `sharp` + `ffmpeg-static`/`lamejs` |
| Нет git | Не блокирует; при желании могу инициализировать позже |
| Нет публичного деплоя | Конфиги + инструкции; деплой после ваших доступов |
| Сгенерированная музыка может не понравиться | Заменяется одним файлом в конфиге; можно прислать свой трек |
| Пустая ссылка на мессенджер | Кнопка скрывается по ТЗ, ничего не «висит» |
